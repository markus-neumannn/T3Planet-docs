You can set up layouts for your pages by following the steps below:

1. Go to the **Page** module.
2. Select the page for which you want to set the layout.
3. Click **Edit Page Properties**.
4. Switch to the **Appearance** tab.
5. Select the **Frontend Layout** from the drop-down menu.
6. Select the **Backend Layout** from the drop-down menu.
