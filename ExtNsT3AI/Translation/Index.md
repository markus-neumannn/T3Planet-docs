The T3AI Translation feature is a powerful tool designed to simplify content translation. With this feature, you can automatically translate your website’s content into multiple languages with just a few clicks.

For TCA, Mask, FlexForm, and related requirements, see [Notes](/ExtNsT3AI/Translation/Notes/Index).

## AI translation

T3AI includes page and content translation tools. Use this workflow to open them:

- **Step 1** — Open the **Page** module and select the page.
- **Step 2** — Edit the page properties.
- **Step 3** — Open the **T3AI** tab.

The features below are documented on their own pages, including interactive demos where available.
