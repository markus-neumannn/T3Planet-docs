There are two ways to use the **Custom LLM** with TYPO3 AI Services (T3AS):

- **Hosting on T3Planet’s Server**
- **Hosting on Your Own Server**

## Part 1: Hosting on T3Planet’s Server

Our server infrastructure is fully optimized for TYPO3 and AI-driven applications, ensuring:

- High performance and fast response times
- Advanced security measures including SSL, firewalls, and automated backups
- Regular updates and maintenance support
- 24×7 monitoring for uptime and stability

<Note>
All deployments, updates, and maintenance tasks are managed by the T3Planet DevOps team to ensure maximum compatibility, security, and reliability.
</Note>

## Part 2: Hosting on Your Own Server

If you prefer to host on your own infrastructure, you are fully responsible for purchasing, setting up, and maintaining your hosting environment.

Please note that external hosting costs are typically higher, and performance may vary depending on server configuration and provider quality.

### Minimum Recommended Server Requirements

- **Server Type:** High-End Server to host T3AS
- **Operating System:** Ubuntu 22.04 LTS or newer
- **Python:** Version 3.10 or higher
- **API Endpoint:** Must expose `/chat/completions` for AI interactions

Once the setup is verified, T3Planet will issue a **T3AS API Key** to enable secure access to the Custom LLM.

<Note>
T3Planet is not responsible for any hosting-related issues, security vulnerabilities, or performance degradation that occur on third-party servers.
</Note>
