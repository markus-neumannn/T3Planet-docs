**Simplify Text** rewrites selected page content into plainer language. Use it
when editors need a simpler version of existing text for the selected page.

## Before you begin

* Make sure the page is already translated (when you work in a translation).
* Configure an AI provider in **AI Foundation → AI Providers**.

## Steps

1. Open **AI Accessibility → Content** (or the Simplify Text
   entry you use in your setup).
2. Select the page in the page tree.
3. Choose **Simplify text** / **Choose a page**.
4. Continue in the TYPO3 Localize wizard when it opens.
5. Review the simplified text before publishing.

## Important notes

* AI generation requires AI Foundation provider configuration.
* Always review output before it goes live.
