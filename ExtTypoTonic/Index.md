TonicTypes (extension key `tonictypes`, Composer package `k3n/tonictypes`) lets you build custom record types in the TYPO3 backend with TCA — without writing a new extension for every content type.

Formerly known as **TypoTonic**. The free extension is published on the [TYPO3 Extension Repository](https://extensions.typo3.org/extension/tonictypes). Optional **TonicTypes Professional** (`k3n/tonictypes_pro`, extension key `tonictypes_pro`) adds advanced field types, MCP tools, toolbar, and related Pro features.

**Compatibility (Core & Professional):** TYPO3 12.4–14.9 · PHP 8.2–8.5
