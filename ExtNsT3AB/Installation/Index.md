# Installation

Installing the T3AB—TYPO3 AI Builder extension is quick and easy. Follow the steps below to add the extension to your TYPO3 environment.

## Premium Version

To install and activate the premium version of T3AB:

1. Download the T3AB extension from the T3Planet marketplace.

2. Install it using the TYPO3 Extension Manager.

3. Activate your license using the official documentation:

   [License documentation](/License/Index)

After installation, the extension will be ready to use in your TYPO3 backend.
