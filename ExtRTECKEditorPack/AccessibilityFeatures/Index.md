Editoria11y is built into CKEditor and helps editors create accessible content while they work.

It checks common accessibility problems, for example:

- Heading structure
- Alternative text for images
- Link text
- Basic color contrast issues

Issues are highlighted directly in the editor, so users can fix them before publishing.

You can run checks in real time while typing or manually from the toolbar.
No external tool is required.

This helps teams improve accessibility earlier and better follow WCAG and European accessibility requirements.
