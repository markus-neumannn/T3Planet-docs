## What This Extension Does

CKEditor Pack for TYPO3 gives you a modern text editor in TYPO3.
It includes more than 40 features for writing and editing content.

It helps with:

- Better content editing workflows
- Accessibility checks (content that is easier to use for all people)
- AI support for writing tasks
- Team collaboration features

The extension is based on open-source technology and integrates cleanly into TYPO3.
It does not require TYPO3 core changes.
