- **Which TYPO3 versions are supported?**

  T3AL is fully tested on TYPO3 v11 and above. For older versions, partial functionality may vary.

- **What AI models does T3AL integrate with?**

  T3AL currently supports ChatGPT, DeepL, Gemini, and more. Additional models can be added via API.

- **How does Crowdin integration work?**

  After generating localizations in TYPO3, you can publish directly to Crowdin with a single click—no extra setup necessary.

- **Can I still edit localizations manually?**

  Absolutely. AI suggestions are simply a starting point. You can override or refine them at any time.

- **Is there a rollback feature?**

  Yes. If you’re not happy with certain AI localizations, you can revert to previous versions quickly.

- **Do I need a Crowdin account?**

  Yes, you’ll need your own Crowdin project and API credentials to sync localizations between TYPO3 and Crowdin.

- **Can T3AL handle large-scale projects?**

  Definitely. T3AL is built for batch localization, handling multiple XLIFF files with minimal performance impact.

- **Is the AI localization secure?**

  We use industry-standard encryption and secure APIs. Your data stays protected throughout the workflow.

- **Does T3AL work with custom extensions?**

  Yes, it supports both TYPO3 core extensions and community or custom extensions that use standard XLIFF files.

- **What languages are supported?**

  T3AL handles all major global languages which are supported by TYPO3, plus niche dialects, depending on the AI model you choose.

- **How do I manage a glossary or terminology?**

  Crowdin’s built-in Glossary feature keeps your terms consistent across every language and update.

- **Will T3AL increase load on my TYPO3 instance?**

  It’s optimized to offload AI processing tasks externally, so performance remains strong within TYPO3.

- **Can I export localizations for offline review?**

  Yes. You can export your XLIFF files at any point for offline editing or backups.

- **Where can I get support?**

  We offer online documentation, community forums, and dedicated support plans for agencies and enterprise users.
