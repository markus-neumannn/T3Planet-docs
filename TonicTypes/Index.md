This documentation set covers **TonicTypes Professional** (extension key `tonictypes_pro`, Composer `k3n/tonictypes_pro`) for T3Planet customers.

Professional builds on free **TonicTypes Core** (`tonictypes` / `k3n/tonictypes`) so you can define custom TYPO3 record types with TCA in the backend — without writing a dedicated extension for every content type. Core remains required for install order, shared plugins, and ViewHelpers; the features, examples, and product framing here lead with **Professional**.

Formerly known as **TypoTonic**. Core is published on the [TYPO3 Extension Repository](https://extensions.typo3.org/extension/tonictypes). Professional adds advanced field types, MCP tools, toolbar, DocHeader, link handler, and related Pro capabilities (license via `ns_license`).

**Compatibility (Core & Professional):** TYPO3 12.4–14.9 · PHP 8.2–8.5
